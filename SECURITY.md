# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Report it at https://github.com/pirlruc/pixeldive/security/advisories/new with a description, the affected version or image digest, and a way to reproduce it. You will get an acknowledgement within 7 days.

## Supported versions

Security fixes land on the default branch and ship in the next release. Older tags are not patched in place.

## What this covers

This repository's code, published images, and reusable workflows. A finding in a third-party base image is in scope when this repository publishes that base as part of its own image.
